## 你的 GitHub 主页在说什么

打开你的 GitHub 主页，你会看到什么？

- 头像 👤
- 用户名 📛
- 简介（可选）✍️
- 组织（可选）🏢
- 星星和.follower 数量 ⭐

> 大多数人的 GitHub 主页，就像一张「数字名片」—— 信息有，但很平淡。

但你有没有想过：**它可以更好**？

---

## 什么是「发光」的 Profile

我说的「发光」，不是指真的发光特效，而是指：

> **让人看了一眼就记住，想点进去看更多。**

一个好的 GitHub Profile 通常具备：

| 元素 | 作用 |
|------|------|
| 封面图 | 第一印象，决定要不要继续看 |
| 精选项目 | 3~5 个代表作，直接展示实力 |
| 徽章组合 | 技术栈、认证、成就的快速识别 |
| 统计数据 | 活跃度、贡献量的客观证明 |
| 个人风格 | 配色、排版、动效，传达审美 |

> 你的 profile 就是你的 **数字展厅**。

## profile-glow-studio 做什么

这个工具帮你做两件事：

### 1. 生成展示文案

你只需要输入：

- 🏷️ 项目名称
- 📝 项目描述
- ⭐ 主要功能
- 🔗 项目链接

工具会自动生成一段适合放在 profile 的「项目推荐语」：

```markdown
### 🚀 Featured Projects

**w0nderful-lab-os** — OS-themed personal blog and lab hub
- Built with Astro + TypeScript
- Local First, No Backend
- [Live Demo](https://w0nderful666.github.io/w0nderful-lab-os/)
```

### 2. 优化 Profile 结构

工具会检查你的 profile：

- ❌ 缺少简介
- ⚠️ 没有精选项目
- ✅ 徽章够丰富
- ❌ 统计数据太少

给出一个「优化清单」，照着改就行。

## 为什么要用工具

你可能会问：**我自己不能写吗？**

当然能。但工具能帮你：

1. **省时间**：不用查模板，直接生成
2. **不漏项**：遗漏的重要元素会提醒你
3. **更专业**：生成的文案更符合 GitHub 的展示规范

> 工具不能替代你的内容，但能让内容的呈现更专业。

## 进阶技巧

除了用工具，还有几个「手动」优化的小技巧：

### 1. 固定精选项目

在仓库设置里，可以把 **3 个项目固定**在 profile 顶部。这是最显眼的位置。

### 2. 用徽章展示技能

常见的徽章：

- ![Python](https://img.shields.io/badge/-Python-3776AB)
- ![TypeScript](https://img.shields.io/badge/-TypeScript-3178C6)
- ![Astro](https://img.shields.io/badge/-Astro-FF5A03)

可以用 [readme-badge-studio](https://w0nderful666.github.io/readme-badge-studio/) 生成。

### 3. 保持更新

Profile 不是设一次就完事的。每做一个新项目，更新一下；每写一篇博客，同步一下。

> **活跃的 profile 比「完美但静止」的 profile 更吸引人。**
