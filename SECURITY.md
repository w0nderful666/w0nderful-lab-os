# Security

`w0nderful-lab-os` is a static, local-first website.

## Privacy Boundary

- No backend services.
- No database.
- No login system.
- No file uploads.
- Settings are stored locally in `localStorage`.
- External links go directly to GitHub Pages or GitHub repositories.

## Reporting

If you find a security or privacy issue, open a GitHub issue with clear reproduction steps and expected impact. Avoid posting secrets, tokens, or private user data.
