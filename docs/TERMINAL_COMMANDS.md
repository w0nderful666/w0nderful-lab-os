# Terminal Commands

Terminal.app is a real local control surface for v0.4.0. It runs in the browser, uses System State, and does not require a backend.

## Basic Commands

- `help`: list available command groups.
- `clear`: clear Terminal.app output.
- `whoami`: print the lab operator identity.
- `status`: print current app, theme, Experience Mode, Motion Speed, Recent Items count, and command history count.
- `version`: print the current Lab OS version.

## Navigation Commands

- `home`
- `projects`
- `blog`
- `timeline`
- `about`
- `settings`
- `terminal`

Each navigation command opens the matching app route through System State.

## Settings Commands

- `theme light`
- `theme dark`
- `theme system`
- `mode performance`
- `mode balanced`
- `mode quality`
- `speed slow`
- `speed normal`
- `speed fast`
- `lang zh`
- `lang en`

Settings commands update System State, localStorage preferences, `html`/`body` data attributes, Settings.app controls, and footer labels.

## Search Commands

- `search pdf`
- `search github`
- `search prompt`
- `search blog`
- `search tool`
- `search local`

Search results are generated by `src/scripts/search-index.ts`, the same module used by Command Palette. Clickable results can open projects, posts, timeline entries, or commands.

## External Command

- `github`: opens the real GitHub profile at `https://github.com/w0nderful666`.

## History

Terminal.app stores the latest 10 commands in System State. Use ArrowUp and ArrowDown to recall command history.
